# 情感被骗指数测试

这是一个关于亲密关系观察与自我判断的网页测试。

系统按题型配额、维度覆盖和语义去重规则随机抽取 28 道有效题。每轮题目可能不同，同一轮中不会出现重复题目。

## 如何使用

在项目根目录启动本地预览服务：

```sh
python -m http.server 8765 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:8765/html/index.html 。答题页需读取独立的 JSON 题库，部分浏览器直接打开 HTML 文件时会拦截该请求，建议统一使用本地 HTTP 预览。

1. 进入首页，点击“开始测试”。
2. 阅读题目，并从四个选项中选择最符合自身情况的一项。
3. 完成全部 28 道题后进入结果页。
4. 如需体验另一组题目，可以点击“重测一次”。
5. 点击“分享结果”可生成包含全部分层数据的结果长图，保存后手动发送给朋友；支持图片分享的浏览器也可直接打开系统分享菜单。

答题过程中刷新页面，当前题目和已经完成的进度会在同一个浏览器标签页中保留。

## 当前状态

- 85 道正式题已录入（全部 valid），包含两道新增止损题；每轮止损至少3题。
- 已恢复正式 28 题问卷，本机可从首页完成答题、刷新恢复和重测一次。

- 支持答题进度恢复。
- 第一至第六层算法已接通，结果页显示最终分数、阶段及各层计算数据。当前评分为 V1.4、抽题为 V4，尚需真人样本校准，不代表已经验证的测评结论。

## 隐私说明

答题记录仅保存在当前浏览器标签页的临时会话中。本项目目前不会把答案上传到服务器；关闭对应标签页或浏览器会话后，临时记录可能被清除。

结果截图在浏览器本地生成，只有你主动保存或分享时才会导出。

## 使用提醒

本测试用于自我观察和互动体验，不构成心理诊断、医疗建议或对现实关系的确定判断。请结合真实情况独立判断，必要时向可信任的人或专业人士求助。
