## 实际异常与修正

先直接提高止损最低来源，保留原抽题流程进行检查。在独立种子10001～20000中，要求至少4题时835/10000次耗尽重试；用户明确允许3题后，直接改为至少3题仍有7/10000次耗尽重试。未以提高重试次数、删除失败种子或放宽其他覆盖规则处理。

根因：当前needed只有A25/C17，scarcity只有A05/C03。各维最低要求2个来源，因此四题均为逻辑必选；先覆盖关键维度的旧流程可能用完C类名额，造成后续必选来源无法入选。新增止损来源使这一隐患更容易暴露。

在候选可用性表达式中增加由题池推导的必要约束：

```text
required = { q | 存在维度k，使q测量k且有效题池来源数(k) = 最低来源数(k) }
reserved(t) = 尚未入选的required题中属于题型t的数量

候选q可用须满足：
selectedCount(t) + reserved(t) - indicator(q属于required) < quota(t)
```

该式等价于「选入q后，剩余题型名额足以容纳该题型尚未入选的必选题」。它不按题目ID、答案、人物或分数设特例，也不修改原阶段、选题优先级排序、填充和洗牌流程。已有容量检查仍负责显式报告题池不足。
