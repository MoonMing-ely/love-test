# 抽题V3：边界证据覆盖修缮与复核

状态：2026-10-15经用户确认写入。此为评分V1.4、抽题V3的历史记录；当前抽题已更新为[V4：止损至少3题](sampler-stop-loss-v4.md)。本文保留候选比较、验证结果与已知限制。

## 推荐与限制

推荐D50guided，作为针对边界来源变化的有限改进：具体边界执行题至少2道，且其最高可得分合计不低于全部边界题最高可得分合计的50%。在原关键维度补齐过程中，将补足此类内容的边际收益加入原优先级。保留原阶段/循环结构、28题、类型配额、12维最低来源、语义上限和100次重试；六层计分表达式、M和题库不变。

开发、验证和新确认样本的稳定答卷换题分差95分位均有改善，旧8画像标准差均下降。整体平均配对分差改善较小，bootstrap区间仍跨0；不能声称显著提升真人信度，也不能认为全部大分差已经解决。若验收要求彻底消除跨阶段大分差，本轮尚不达标。

## 约束与表达式

具体执行类按现有semantic_group识别，对应A31/B10/B18/C06/C09/C10，分别涉及不愿亲密配合、过度承担、拒绝请求、承诺压力、帮忙与自身事务、遭受情绪伤害后的界限。判定还要求题目确实计入boundaries。没有按人物、答案或最终分数设特例，也未删掉其他边界证据。

```text
executionCount >= 2
executionCapacity / totalBoundaryCapacity >= 0.50
priorityCoverageGain(q) = missingDimensionCount(q) + missingExecutionCoverageGain(q)
```

missingExecutionCoverageGain仅在关键维度补齐阶段、具体执行题不足2道且候选属于该类时为1，否则为0；其余优先级保留。50%是工程候选约束，不是心理学确定的最优比例。容量由题目最高分决定，与本人的答案无关。原Raw/Capacity、各层控制和总分映射完全保留。

## 研究设计

开发256人、验证128人，沿用先前冻结答卷；另预先生成128名新模拟者，待候选预选后才打开其分数。每人三种条件各20次：固定全题库答案换题组、固定题组状态改变、换题与状态同时改变。另有8个冻结画像各300组题。生成器仍使用原评分键和人为设定的情境、经历、响应偏差，模拟不是独立真人效标。

共比较9种配置（含基线）。第一轮比较生成后内容约束；第二轮比较将内容缺口加入原边际覆盖优先级，以及40%/50%容量约束或独立退出选择覆盖。确认集打开后未再调参。预先偏好开发和验证均有10%以上稳定分差改善，但该幅度未达到；确认集有所改善也不追溯改变先前标准。

## 低分与尚未解决的尾部

新确认样本中，边界类稳定换题低于20分的评分次数35→14（各320次），出现过此类分数的人数仍为3/16。综合条件低于20分次数50→34，出现过的人数仍为8/16。因此减少了低分出现次数，未消除所有人的低分。

全部确认样本：稳定换题低于20分517→493；固定题组状态变化460→474；综合512→479。不同生成规则抽出的题组不同，不能把同种子逐项升降解释为同答卷提分或降分。固定状态同一人的旧/新题组间仍存在从≥50到<30的个例，需继续检查。

新确认样本128人中，仅换题时个人极差>30分人数23→16，但既出现<30又出现≥50分的人数11→16；综合条件两项人数分别43→37、27→22。阶段阈值与均值移动会影响此统计，不可只挑改善项。
