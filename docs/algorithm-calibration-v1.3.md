日期：2026-10-15。用户确认本方案改善尚不全面，但可以写入。本轮已实施统一标尺，其他修缮方向仅提出方案，未混入正式计分。

## 已写入的算式

记R为V1.2原有计算经M保护后的证据分：

```text
S(R) = 15 + 0.5R                 0≤R≤30
       R                        30<R≤70
       70 + (5/7)*(R−70)         70<R≤91
```

锚点集中在`AlgorithmConfig.LAYER6.SCORE_ANCHORS`：[0,30,70,91]→[15,30,70,85]。第六层用统一线性插值定义最终分，不按画像、题号或0分特判，不改变前五层的计算。

15/85为产品标尺锚点，不是受骗概率。页面保留名义100分指数标尺，当前公式可达范围15～85。阶段仍以30/50/70分界，所有原始分阶段严格不变。理论原最大91来自最大路径严重度75与最大增益16；未来改变这些参数时必须复核标尺上端，不能悄悄裁剪。

## 保留与解释

- 原P1～P4、High/Low、平滑激活、锚点、深度、均值兜底、多路径增益与M计算不变。抽题约束、题库、答案快照和缺失规则不变。
- `debug.evidenceScore`保存R；`preScore/protectionAdjustment`仍为证据分单位。结果页明确区分证据分和最终指数，不在界面内重新实现映射。
- M在证据分中仍最多减8。显示作用随区间缩放：50→42仍为50→42；91→83显示85→79.29；20→16显示25→23。没有移除保护，但不能把原证据分修正直接称为每处最终指数同幅修正。
- null/insufficient_data在映射前返回，不能当成0再生成15分。15只来自完整答卷。
- 映射连续、严格递增，各段斜率0.5、1、5/7；任何两份答卷的数值差都不放大。它改变尺度，不增加测量信息或证明预测准确度。

## 其他方向：按优先级推进

### 1. 区分未遇到经历与实际保护能力

现B题“从未”可以同时来自“没有遇到该情境”和“遇到了也未失守”。当前按同样分值解释，可能把经验不足当成充分保护；前轮固定性格、只切换经历覆盖的模拟已发现明显差异。不能单靠原答案推断真实经历，也不能因经验少而加风险。

候选是独立记录题目或情境是否适用，并统一定义有效证据：

```text
Value_d = sum_j(eligible_j * score_jd) / sum_j(eligible_j * capacity_jd)
```

eligible来自独立适用信息，不从“从未”自动生成。有效信息不足时保留数据不足或证据不足，而非0分保护。本方向代价是需要额外题目信息与结果解释；可能减少部分新手可用的经历证据。题干/选项与流程需单独审核，本轮未改题。

### 2. 按完整链路限制跨维题影响

重点审查A08认可/特殊性、B03边界/止损的证据是否被重复放大。先核对题意究竟支持几个维度、各自强度，再比较一致的题目权重与容量表达式：

```text
Value_d = sum_j(w_jd * score_jd) / sum_j(w_jd * capacity_jd)
```

调整分子必须同步分母，不能只缩小原始分造成方向错误。权重也不能按某个人得到的分数临时改变。以离线相邻替换分差和同人稳定性作为约束比较候选，而不是在运行时强制截断某次分差。

收益是抑制单题的跨维杠杆；代价是改变原证据贡献，需重新跑题库、来源和全人群对照。不是把所有多维题一律减半，也不预先认定某个权重正确。

### 3. 让随机题组更可比，而不只增加条数

可比较关键维度的情境分层、部分共同锚题与其余随机题组合，以及有效容量范围。共同锚题需覆盖不同情境并先审核，不能让一题成为唯一代理。固定部分锚题可降低题组漂移，代价是暴露、重复记忆与随机自由度减少。

前轮提高认/特/边/止至3题、或再要求2道B边界题，在旧画像和开发模拟中有收益，但新偏差样本未稳定改善；本轮未采用这些约束。来源数不等于独立信息量。

### 4. P4中区分实际停止困难与心理分化弱

一个较尊重旧机制的研究候选为：

```text
core4 = 0.5*max(T弱,F弱) + 0.3*T弱 + 0.2*min(T弱,F弱)
```

停止更弱时与旧式相同；分化更弱时仍保留50%短板主导，低于原80%；双弱仍为1。它比固定停止80%/分化20%温和，但仍会降低一部分画像得分。应在明确的“能实际停止但心里纠缠”与“分得清但停不下”答卷上先做构念判断，本轮未实施。

### 5. 证据冲突与覆盖单独解释

自陈很强、行为题较弱，可能来自自我美化，也可能是情境差异或经历不足。可呈现哪些维度来源少、哪些证据冲突，但不直接当作不诚实扣分，也不自动削弱M。不应在未标定时提供看似精确的置信概率。

## 建议顺序

先审核经历适用信息和A08/B03等跨维证据，再用有效性与容量一致的表达式验证；随后比较情境分层/锚题。P4的构念调整单独评估。最终需在状态稳定的真人重复作答中核查，而不是继续只围绕固定画像拟合。历史P2定义与对照见[V1.2说明](algorithm-calibration-v1.2.md)。
