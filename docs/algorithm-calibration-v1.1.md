# 算法 V1.1：保留机制的参数校准

日期：2026-10-15。本文件记录V1.1历史基线；当前实现已增加[V1.2的P2证据修正](algorithm-calibration-v1.2.md)。此前实验D/E及画像目标拟合均未写入正式算法。

## 决策依据

用户最终明确：**原机制优先，画像目标允许偏离**。因此不再为实现10/30/40/65/85等目标而重写第五、第六层计分。M仍只抵减已有风险，不新增独立易感分；近极端答卷仍可能为91，不强压为85。

此次修改直接改变原有表达式使用的参数，没有新增事后分数修正、运行时替换函数、按画像特判或第二套计分链路。

## 保留的机制

- 第一层原始累计、第二层本轮Raw/Capacity、第三层结构归纳不变；题库题干、选项、分值不变。
- 第四层继续用有起点和饱和点的High/Low，保留低端过滤与高端饱和，未替换成全区间直通。
- 第五层P1保留峰值80%/次峰值20%；P2保留高E与低J的合取及H/判断短板支持；P3保留高J与低B的合取；P4保留较弱项80%/另一项20%和E支持。整个第五层文件未修改。
- 第六层保留Smooth激活、锚点40/52/60/65、25倍深度调节、70倍均值兜底、max计分主体、连续多路径增益、Shape/Path匹配及平方解释权重。
- M保护仍为 `-8*M*min(1,preScore/40)`：最多减8分，低分时最多减20%，不以自报保护直接抹去已有风险。未引入基线5分、独立M风险、平方行为计分或85分封顶。
- 缺失维度仍返回null/insufficient_data，不用0补齐。阶段30/50/70不变；标签切换不参与计分分支。

## 改动的参数

| 参数 | V1.0 | V1.1 |
| --- | ---: | ---: |
| HIGH_START | 0.35 | 0.20 |
| HIGH_FULL | 0.75 | 0.80 |
| LAYER6.ACTIVATION_BEFORE | 0.05 | 0.20 |
| LAYER6.ACTIVATION_AFTER | 0.10 | 0.25 |

第四层仍为：

```text
High(x) = clip((x-0.20)/0.60,0,1)
Low(x) = High(1-x)
```

原来的线性区间宽0.40，现在宽0.60，区间斜率由2.5降到约1.67。0.76与0.96不再都立即视为完全高，但0.20以下/0.80以上仍保留过滤和饱和。

第六层仍为：

```text
activation_i = smooth(P_i; threshold_i-0.20, threshold_i+0.25)
severity_i = activation_i * [anchor_i + 25*(P_i-0.60)]
baseSeverity = 70*mean(P)
pathSeverity = max(baseSeverity,severity_1,...,severity_4)
preScore = pathSeverity + shapeAdjustment
Score = clip(preScore - 8*M*min(1,preScore/40),0,100)
```

激活宽度由0.15变为0.45。仍是原有平滑控制，而不是移除激活门。高程度充分激活时，锚点与深度的原有含义不变；全P=1时M=0为91分，M=1为83分。

抽题的认/需/特/稀最低来源各从1提高到2，其余八维仍至少2题；28题、A12/B6/C6/D4、同语义组最多2题、最多100次尝试均不变。没有把边界/停止另提高到3或4。需要/稀缺各只有两道题，覆盖提高后它们会每轮必出，随机自由度相应减少。

## 版本与存储

`AlgorithmConfig.VERSION`、第四层和第六层版本为1.1；第五层仍为1.0，第三层仍为1.1。抽题`SELECTION_VERSION`升级到2。存储信封V3和键名不变。

旧抽题进度不混入新覆盖规则，重新打开答题页时按既有失效流程重新生成。结果页加载配置并核对第六层版本；旧算法结果只提示重测，不显示或重解释旧分数，也不自动重算/覆盖旧答卷。新版结果刷新继续显示原始保存值。

## 参数对照

先分别比较覆盖、第四层过渡、第六层激活，再比较组合。过宽平滑会降低中度风险画像与稳健画像的分离，因此选择较小幅度的参数组，而非只优化单题最大变化。

同一正式83题库，各画像固定全部83题答案，1000种子生成正式28题：

| 行为画像 | V1.0均分 | V1.1均分 |
| --- | ---: | ---: |
| 谨慎且有边界 | 0.00 | 0.05 |
| 容易心动但有边界 | 37.01 | 33.58 |
| 怕错过但不接受反复伤害 | 39.79 | 34.18 |
| 享受被需要且有边界 | 37.22 | 37.23 |
| 偶尔动摇且能够调整 | 39.56 | 38.60 |
| 容易心动并忽略证据 | 69.68 | 71.93 |
| 看得清却难拒绝 | 65.25 | 62.80 |
| 能看清、能拒绝但难结束 | 75.19 | 71.96 |
| 多方面持续失守 | 91.00 | 91.00 |
| 行为稳健但过度自信 | 0.00 | 0.07 |

覆盖规则不同意味着相同种子可能抽到不同题组；表格是同一画像回答规则下的抽题实验，不是同卷配对或真人验证。“稳健但过度自信”不强拉到30：原M机制在没有已激活风险时不凭空制造风险，这符合最新确认的取舍。

500个额外种子，各28题替换其余3选项，每设置42000次替换：计分相邻替换的最大分差由约56.01降至41.79，95%分位由11.24降至10.10。覆盖单独提高并不能消除过陡变化；更宽激活虽能进一步降低极值，也会压缩部分画像差异。

## 验证与限制

- 全部14个Node测试通过；覆盖正式题库1000次抽题、全评分链路、10000组第六层连续性/方向、M保护、单/双路径、锚点深度及失效记录。
- 隔离Firefox在1440×900和390×844各完成一轮真实28题；答题中刷新、结果刷新、六层显示、旧结果提示重测、旧抽题版本失效通过。页面保存分数与独立调用正式纯模块得到的值完全一致。此为功能验证，不是140%缩放下的视觉验收。
- 单题波动仍大，没有达到前期自定的最大15分目标；这是未解决限制，不能宣称已经完成最终测量校准。
- P3仍表达“看得清却做不到”，所以提高J可增强该路径；不宣称单独提高12维中的任一保护能力必使总分下降。第六层对四个风险输入不减、对M不增的性质继续保留。
- H仍只作为P2支持，心理分化与停止仍按较弱项主导；保留这些规则，不表示此前反例已全部修复。改变其含义需要独立的构念与证据审查。
- D08的边界计分归属、经历题“从未”与未遇情境的混淆、不同题组的可比性尚待复核。本轮未擅自改题。
- 所有分数是产品易感指数，不是被骗概率；画像模拟不能代替真人信度、效度或人群切点校准。
