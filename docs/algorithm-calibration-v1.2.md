# V1.2：保留旧通道的P2证据修正

日期：2026-10-15。本文件记录V1.2的P2修正；当前已叠加[V1.3的统一标尺定义](algorithm-calibration-v1.3.md)，本文件中的最终分均为旧证据分。本轮按“单项方案→新模型与对照→方向性复核→小范围实施→全链路验证”执行。此前整套P2/P4/第六层/抽题候选没有整包写入。

## 本轮决策

只写入P2证据修正。第六层数学表达式及全部参数、P4短板保护、抽题最低2题、题库、第一至三层均保留。未采用0.75P+0.25激活、多路径提前至0.10～0.30或8/8增益，也未采用固定停止80%/分化20%。

目标优先级仍为原机制优先、画像目标允许偏离；不为稳健10分、自信30分或极端85分新增修分、基线或封顶。

## 定位与实际表达式

原P2核心 `min(High(E),Low(J))` 使低情感时的判断短板无法启动；合理化H也只能放大已经存在的核心。这会让某些明确不良的行为模型接近零分。

记e=High(E)、j=Low(J)、jw=Low(J_weak)、h=High(H)、gap=High(J_hole)：

```text
core = min(e,j)
support = max(h,gap)
relationship = core * [1 + 0.25*(1-core)*support]
judgment = 0.8*j
weakJudgment = 0.5*jw
avoidance = 0.45*h
P2 = max(relationship,judgment,weakJudgment,avoidance)
```

旧P2完整表达式成为relationship，其输入、支持、强度均未改。新增三种证据与旧通道竞争，不求和、不再乘一次H支持。H在原通道只作一次支持，在avoidance候选只用一次；最终取最大值，避免把H先作为核心再用H放大同一核心。

几个系数是工程候选权重，不是心理研究估计值。强H单独约16分，修复了零分，并不意味着已确证其真实风险应为16。

第四层集中新增`fuzzy.low_J_weak`；第五层读取它，避免复制High/Low表达式。原有`core2/support2`仍指旧通道；debug新增`P2_relationship/P2_judgment/P2_weak_judgment/P2_avoidance`，用于追踪分数证据。没有增加第二套运行时评分链。

## 为什么没有直接写入上一轮候选

发现一个方向性副作用：若先将新增判断短板放入core，再把J_hole支持乘在整个core上，单项判断能力增强而P2略升的随机案例约从6%扩大到25%。这版未写入。

改为保留原完整通道、独立证据最后取最大值后，新增证据本身对判断能力提升均不增，故不会产生原通道之外的新逆向变化：若原通道不增，几个候选均不增，其最大值也不增。

原J_hole支持仍有少量旧方向例外，并未擅自删去。5000组随机输入、各判断项增加0.05：旧版三项分别约297/298/295例轻微增加，新版43/38/53例；观测最大P2增幅约0.001736。单独提高J并不保证全总分下降，因为P3原本表达“看得清但做不到”，这个含义也保留。

## 未写入的后续方案

### P4保留短板的折中候选

```text
core4 = 0.5*max(T弱,F弱) + 0.3*T弱 + 0.2*min(T弱,F弱)
P4 = core4 * [1 + 0.15*(1-core4)*High(E)]
```

当停止更弱时与旧式完全相同；分化更弱时从80%主导降为50%，保留一半短板贡献，双弱为1。相较固定停止80%/分化20%，这版更尊重旧机制。

500题组对照：分化弱但能退出的旧画像由43.39降至33.90；新低情感分化弱模型由45.88降至12.91。虽较温和，仍实质改变F的保护强度，因此本轮不与P2一起写入。下一步需用明确区分“分得清”“真能停止”的新行为题答卷复核其含义，再决定比例。

### 边界/止损至少3题

独立提高题量会改善某些止损模型的稳定性，但也改变取题构成。新强情感/停止弱模型均分约60.66→71.76；旧“分得清但难止损”约58.48→67.94。不能把变稳直接等同测量更准。本轮维持原2题，后续需先解释题组可比性再决定是否提高。

### 第六层

继续保留全门控、40/52/60/65锚点、25深度、70均值兜底、原4/12多路径增益、M最多减8及低分比例保护。优先查B03跨维联动、有效容量与既有激活斜率，避免用降低严重度再提前增加共现分数互相抵消。本轮没有生成新的第六层修分。
