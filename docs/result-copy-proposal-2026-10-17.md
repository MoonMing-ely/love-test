# Love-test 定向调查与结果文案初步方案

日期：2026-10-17；修订：2026-10-18。状态：讨论稿，尚未接入产品。

**最新验收依据：[结果文案验收标准](result-copy-acceptance.md)。** 旧版分档名称与长篇固定说明已撤回；类型名仍待拟定。

目标呈现：**分数 → 容不容易受到情感欺骗影响 → 基于 Stage 的类型 → 基于突出维度的人物描述。** 本文按用户最新方向细化，作为[上一轮调查](result-copy-research-2026-10-17.md)的后续方案。

本文中的命名、描述、维度阈值和选择规则均为候选。只新增方案与研究附件，不修改题库、评分、接口或页面。竞品观察、产品设计建议和构造数据回放分别说明。

## 1. 本轮调查要回答的问题

1. 怎样用“你是某某型”形成识别感，而不让名字编造具体性格？
2. 怎样写出“你具有某种特点，因而在某类情境下可能怎样”的自然描述？
3. 怎样从十二维里选择最值得说的两三个特点，避免排名制造假突出？
4. 怎样让同分用户读到有差异的描述，并保持硬编码结果稳定？

本轮只检索公开官方页面、样例报告与解释指南；没有购买报告、注册账号或提交用户答案。没有找到对照证据证明下面哪一种命名最受目标读者欢迎，因此文风与名称仍需后续试读。

## 2. 定向调查：具体观察与设计取舍

### 2.1 类型名怎样变成可记住的人物印象

**观察：** 16Personalities 的类型列表将 Architect、Mediator 等名称与一句人物概括并列；单个类型页再展开特点和关系表现。[官方类型列表](https://www.16personalities.com/personality-types)、[Mediator 示例](https://www.16personalities.com/infp-personality)。

**本方案采用：** 给用户一个简短类型名，紧接一两句解释，随后进入有差异的个人描述。用户不需要先学习 Stage 或算法术语。

**限制：** 这些类型来自多特征组合，不能据此认为 Love-test 四个总分等级也能代表四种完整人格。“理性观察者／深情奉献者／执着守候者”很有形象感，却分别需要判断、被需要、止损等不同证据，不能直接分配给 Stage 1—4。

### 2.2 如何让四种类型各有含义，而不只是四个好听的名字

**观察：** Gretchen Rubin 的 Four Tendencies 围绕对内外期待的反应定义四种倾向，并为每种倾向提供核心口号、优势和困难。[官方框架](https://gretchenrubin.com/four-tendencies/)。

**本方案采用：** 名称必须对应清楚、稳定的测量含义。每档只概括整体易感程度，具体“为什么”留给维度。类型说明应能让作者明确回答：这句结论由哪个字段支持？

**限制：** Four Tendencies 的四类不是从低到高的风险等级。本项目不能照搬其类型或把四个 Stage 解释成四种独立人格结构。

### 2.3 怎样从一组特征写成“这个人”的描述

**观察：** Truity 的 7 Love Styles 样例先呈现各项分数，再详述主要风格，补充次要风格；描述包括具体需要、情境表现和表达方式。[官方样例，第 3—7 页](https://www.truity.com/sites/default/files/fillpdf/sample_7_love_styles_report.pdf)。

**本方案采用：** 正文围绕一个主要特点展开，再用第二个特点补充它，必要时加入一个保护特点。整体形成“容易被什么打动—如何判断或行动—有什么能稳住自己”的叙述。

**限制：** 页面结构不证明其后台采用特定拼接规则。Love-test 的正文也不强制每次覆盖这三个环节；缺少证据的环节允许不写。

### 2.4 “最突出”为什么不能只取最高分

**观察：** VIA 的解释指南区分原始数值与排序，指出排序本身不能充分说明差异；并列与很小分差应谨慎解读。[官方解释指南，第 4—5 页](https://www.viacharacter.org/pdf/VIA%20Total%2024%20Report%20Interpretation%20Guide.pdf)。

**本方案采用：** 先判断是否有足够明显的信号，再从中选择，而不是无论如何都取前三名。保护能力与风险倾向分别理解，并列特点不用“你最大的弱点”之类措辞。

**限制：** VIA 的量尺、具体差值建议与 Love-test 不同，不能移植。本文后面的数值是编辑试验参数，不是经过验证的心理学界限。

### 2.5 能否在不实时生成的情况下写得自然

**观察：** BigFivePersonalityTest.org 的方法页明确说明基础报告使用预写内容，并把文案分段称为编辑区间。[官方方法页](https://bigfivepersonalitytest.org/methodology)。

**本方案采用：** 提前写好、审核完整段落，运行时根据结果选择。优先为常见组合精写衔接段，减少逐词拼接。

**限制：** 这是该产品的公开自述，不代表全部同类产品，也不证明其分段适合本项目。

### 调查形成的具体判断

可借鉴的是“简短标签、主要与次要特点、具体情境、预写文本”；本项目需要自行决定的是“四档命名、维度显著规则、组合条件、中文文风”。以下方案属于这些观察的设计推导。

## 3. 首版结构：判断一句，特点两三句

用户可见文字按新验收标准压缩：判断最多 18 个汉字，特点最多 80 个汉字。删除重复判断的固定说明。

```text
64.4 分
受骗倾向：第 3 档（共 4 档）

你能看出问题，却不太容易拒绝对方。
遇到不合理的要求时，你可能仍会让步。
```

统一方向说明：“档位越高，受骗倾向越强。”

类型位置仍保留在方案中，名称另行拟定。当前示例只验收判断与特点，不代表类型名已完成。

共用说明只出现一次：“结果仅供自我了解，分数不代表受骗概率。”

## 4. 分档表达：统一编号

| Stage / 当前区间 | 程度标识 |
| --- | --- |
| 1：15 ≤ x < 30 | 受骗倾向：第 1 档（共 4 档） |
| 2：30 ≤ x < 50 | 受骗倾向：第 2 档（共 4 档） |
| 3：50 ≤ x < 70 | 受骗倾向：第 3 档（共 4 档） |
| 4：70 ≤ x ≤ 85 | 受骗倾向：第 4 档（共 4 档） |

统一方向说明：“档位越高，受骗倾向越强。” 四档只改变编号，不追加强弱形容词。

编号消除词语带来的程度歧义，但不表示真实风险等距。现有算法和分界不变。

原先的“低／偏低／偏高／高”撤回。词形对称不能保证感受上的间距一致。

程度标识与性格类型仍分开。类型名须简短、日常、含义明确，不能从总分编造具体性格，也不能直接用档位替代。

## 5. 突出维度怎样选择：可执行的初步规则

### 5.1 先统一字段含义，不统一高低好坏

以下使用本轮维度的归一化值 `v`，范围 0—1，字段按稳定 key 映射。

- 风险倾向：`recognition`、`needed`、`specialness`、`scarcity`、`rationalization`。较高值可进入风险特点候选。
- 保护能力：`calibration`、`evidence`、`manipulation`、`boundaries`、`stopLoss`、`differentiation`、`selfCalibration`。较低值可进入风险特点候选，较高值可进入保护特点候选。
- 缺失、未知或旧版本结果：不生成相应个人描述。低认可敏感不直接被包装成“自信”；低风险倾向也不自动成为保护能力。

归一化数据有字段别名，后续实现应建立显式映射，例如 `needed → traits.need`、`boundaries → traits.boundary`、`stopLoss → traits.stopping`；不能把题库 key 原样套到所有层级。

### 5.2 候选进入条件

为让方案具体可讨论，先提出：`v ≥ 0.65` 为高侧候选、`v ≤ 0.35` 为低侧候选，其余不单独写成突出特点。对应强度可以用 `|v - 0.5|` 做初始排序依据。

**这些数值只作为文案选择实验参数**，未写入代码，不是常模、显著性界限，也不改变现有算法的 High／Low 隶属度。不同维度同为 0.7，不代表具有相同心理强度；排序只是首版编辑启发式，需要用代表画像复核。

### 5.3 从候选里选两到三个，而不是固定取前三

1. **优先检查现有入选 Path 对应的维度候选。** P1 关联前四项，P2 检查判断三项与合理化，P3 检查判断与边界，P4 检查止损与心理分化。M 可提供保护补充。这里只表示相关范围，不直接推断成因。
2. **若命中组合段，优先使用组合段。** 例如判断能力较高而边界较低，直接写“看得出问题但难以拒绝”，不拼两段互不相干的介绍。
3. **否则先选一个主要风险特点，再补一个独立特点。** 同一主题最多占一个位置，例如认可敏感与特殊性放大可以合并成“被理解与特别感”，不占满整段。
4. **有足够明确的保护候选时，允许补一个保护特点。** 不能为了安慰强行找优点；保护也不抵消文中所有风险。
5. **主要风险与保护都没有进入候选时，使用中性回退段。** 即使算法选出了 Path，也不降低维度门槛强行制造特点。

主要风险的排序：入选 Path 的相关候选优先；再按上述候选强度排序；完全相同按既有维度顺序稳定选择。保护候选按其高侧值选择，但与正文重复的跳过。接近并列的前两项不称“最突出”或“唯一弱点”；可先把差值不超过 0.05 作为编辑上的近似并列，仍待验证。

输出最多覆盖三个维度主题。两个主题足够时就不补第三个。前四个关系价值维度默认合并为一个大主题，判断三项默认合并为一个大主题；合理化、边界、止损、心理分化、自我校准可以独立成主题。

### 5.4 各侧特点的表达素材

以下是内部句意素材，尚未全部通过新版长度验收。正式使用前须压缩为日常短句，避免连续重复“你”。

| 维度 | 高侧可用句意 | 低侧可用句意 |
| --- | --- | --- |
| 人格认可敏感 | 你很看重被理解、被肯定的感觉，对方的认可容易让这段关系在你心里变得更重要。 | 不作为默认主特点，也不据此推断自信独立。 |
| 被需要敏感 | 当对方表现得很需要你时，你容易产生继续陪伴、继续承担的念头。 | 不据此推断冷漠或不愿付出。 |
| 特殊性放大 | “我们之间不一样”的感觉，容易让你更看重这段关系。 | 不据此推断缺乏浪漫或只看利益。 |
| 稀缺性判断 | 你容易在意“错过以后，还能不能再遇到”，这会让放弃一段关系变得更有分量。 | 不据此推断客观选择更多。 |
| 现实回避／合理化 | 面对让你不舒服的表现，你可能会先替对方寻找解释，暂时放下原本的疑问。 | 不直接等同于判断全面可靠。 |
| 关系校准 | 你会留意关系实际走到了哪一步，并据此调整自己的期待。 | 你的期待可能不容易随着关系的实际变化及时调整。 |
| 行为证据意识 | 你重视对方持续做了什么，承诺之外的行动也会影响你的判断。 | 对方说得如何，可能会比是否持续做到更容易影响你的判断。 |
| 操纵识别 | 你会留意施压、推卸责任等不合理互动，较能意识到其中的问题。 | 面对施压或责任转移，你可能不容易及时辨认其中不合理的部分。 |
| 投入边界 | 在时间、金钱和精力的投入上，你会给自己保留界限。 | 面对对方的要求，你可能会让出原本留给自己的时间、精力或其他界限。 |
| 止损能力 | 当你确认关系不合适时，你较能把停止投入的决定付诸行动。 | 即使已经意识到关系不合适，你仍可能很难真正停止投入。 |
| 心理分化能力 | 对方的情绪和评价会影响你，但你仍较能保留自己的感受与立场。 | 对方的情绪或评价，可能会较深地影响你对自己的看法与选择。 |
| 自我校准能力 | 你愿意回头检查自己的判断，也能接受原来的看法需要调整。 | 形成一种看法后，你可能不容易再回头检查它的依据。 |

这些句意不增加“童年缺爱”“天生讨好”“伴侣正在操纵”等未测量结论。具体时间、聊天频率、金钱数额和真实经历也不自行编入。

## 6. 优先预写的六类组合

以下长段只保留为内部组合逻辑说明，不可直接上线。正式文案须按新版长度标准压缩。高／低沿用上一节候选定义，条件同时满足才使用。

| 组合 | 候选条件 | 预写段落方向 |
| --- | --- | --- |
| 容易被打动，但能控制投入 | 前四项至少一项高；边界和止损均高 | 你容易被关系中的认可或特别感打动，但在实际投入和是否继续上，仍有自己的界限。心动会影响你，却不一定会立刻变成让步。 |
| 看得出问题，但难以拒绝 | 判断三项均高，边界低 | 你能留意对方的行为是否可靠，也有识别不合理互动的意识。但面对具体要求时，你可能仍会让出原本的界限。对你而言，更需要留意的是，判断能否转化成一次明确的拒绝。 |
| 能日常设限，却难以离开 | 边界高，止损低 | 对一些具体要求，你能保留自己的界限。但当问题变成要不要结束这段关系时，行动可能会困难得多。你需要留意的，是已经决定不再继续之后，自己能否真正停下来。 |
| 特别感强，行为核对不足 | 特殊性放大高，行为证据意识低 | “我们之间不一样”的感觉容易打动你。当这份特别感很强时，对方是否持续兑现承诺，可能没有得到同样多的关注。 |
| 习惯解释，也愿意修正 | 合理化高，自我校准高 | 遇到不舒服的表现时，你可能先替对方寻找解释。但你也愿意回头检查自己的判断。能否认真看待后来的行为变化，会影响这些解释是帮助你理解关系，还是让问题继续被搁置。 |
| 既难放弃，也易受评价影响 | 止损低，心理分化低 | 即使已经看见关系不合适，你也可能难以真正停止投入。与此同时，对方的情绪与评价容易影响你的立场，让你在作决定时更难顾及自己的感受。 |

同一字段被多个组合使用时，不同时堆叠所有段落。优先与入选 Path 相关的组合，其次选择覆盖更强候选的组合；仍并列时按上表顺序。选中后，其已覆盖特点不再重复输出。

例如最后一类同时存在“难退出”与“容易受评价影响”，可以描述二者并存；不能进一步声称“所有退出困难都是评价造成的”。

## 7. 用真实算法算出分数的七份文案样例

为避免随手写一个分数却与画像冲突，本轮直接构造第四层输入，通过当前正式第四、五、六层计算。它们**不是用户答案，也不是来自正式题库的 28 题答卷**；仅检验“这些维度与这些分数／Stage 能否在当前计算中共存”。

完整输入与输出见[构造画像附件](result-copy-proposal-profiles-2026-10-17.json)。下列分数为一位小数展示示意；生产界面精度与临界显示规则尚未确定。每例共用一句末尾说明：“结果仅供自我了解，分数不代表受骗概率。” 类型名未定，本节不冒充完整类型展示。

### A. 整体较稳：20.1 分 / Stage 1

证据：判断、边界、止损、心理分化、自我校准均为 0.70；前四项与合理化均为 0.30。无入选 Path。

> **20.1 分**
>
> 受骗倾向：第 1 档（共 4 档）
>
> 你会看对方是否说到做到，也能守住自己的界限。确认不合适后，你较能停止投入。

编辑说明：多个保护特点并列，不宣称其中哪项“远强于其他项”。

### B. 容易心动，行动仍稳：44.4 分 / Stage 2

证据：认可敏感 0.85、特殊性放大 0.80；边界与止损均为 0.70。Path 为关系价值入口。

> **44.4 分**
>
> 受骗倾向：第 2 档（共 4 档）
>
> 你容易被认可和特别对待打动。但在付出多少、要不要继续上，你仍有自己的界限。

### C. 关系分量重，判断容易偏移：64.6 分 / Stage 3

证据：认可与特殊性均为 0.75；行为证据意识 0.20，合理化 0.75；自我校准 0.70。Path 为关系价值入口与判断盲区。

> **64.6 分**
>
> 受骗倾向：第 3 档（共 4 档）
>
> 你容易被特别对待打动，却较少核对对方是否说到做到。不过，你也愿意重新检查自己的判断。

编辑说明：这一段选择认可／特别感、证据意识与自我校准三个主题。合理化虽也较高，但首屏不再全部罗列，可留在详细维度说明。

### D. 能判断，却难落实边界：64.4 分 / Stage 3

证据：判断三项均为 0.85，边界为 0.15。Path 为行动失守。

> **64.4 分**
>
> 受骗倾向：第 3 档（共 4 档）
>
> 你能看出问题，却不太容易拒绝对方。遇到不合理的要求时，你可能仍会让步。

**C 与 D 只差约 0.2 分、Stage 相同，正文仍应明显不同。** 这也是不把 Stage 3 命名为“盲信型”或“判断薄弱型”的直接理由。

### E. 日常边界尚可，真正离开较难：69.4 分 / Stage 3

证据：边界 0.70、止损 0.15、心理分化 0.20。Path 为退出困难。

> **69.4 分**
>
> 受骗倾向：第 3 档（共 4 档）
>
> 你能拒绝一些要求，但较难结束一段不合适的关系。即使决定不再继续，你也可能放不下。

编辑说明：优先呈现边界与止损的反差。心理分化低不在此段继续展开，避免首屏堆满风险。

### F. 多处信号明显：83.3 分 / Stage 4

证据：特殊性放大 0.85、被需要敏感 0.80；止损与心理分化均为 0.20。Path 为关系价值入口与退出困难。

> **83.3 分**
>
> 受骗倾向：第 4 档（共 4 档）
>
> 你容易被特别对待打动，也在意对方是否需要你。即使看见关系不合适，你也可能难以停止投入。

编辑说明：选择关系价值与止损两大主题。没有因分数高就写“已经被骗”“没有判断力”，也没有把其他低能力全塞进首屏。

### G. 维度都在中间，不能制造突出特点：37.5 分 / Stage 2

证据：全部第四层输入为 0.50。算法选出判断盲区与行动失守两条 Path，但没有维度满足本方案的高低候选条件。

> **37.5 分**
>
> 受骗倾向：第 2 档（共 4 档）
>
> 这次结果中，没有特别突出的单一特点。你可以回看具体回答，判断哪些更像平时的自己。

回退段会牺牲一些“被说中”的感觉，但比把并列中间值强行写成鲜明人格更可信。它也是必须保留的正式状态，不是错误页。

## 8. 怎样写成稳定、可维护的硬编码

建议未来增加独立解释模块，输入现有 `layer6Integration` 与归一化维度，输出已选文案。模块不改分数、不重新选 Stage，不向外发送答案。

候选数据流：

```text
现有结果与算法版本
  → 校验完整性
  → 读取 Stage 判断句与类型
  → 映射维度，形成高低候选
  → 检查 Path 相关性与组合段
  → 选择最多三个主题并去重
  → 返回主文案和开发用选择理由
  → 页面显示
```

每条文案记录 ID、适用条件、正文、覆盖主题、冲突条目与审阅状态。同一结果、同一文案版本始终得到相同内容；不引入随机换词。

初版预计需要：

- 四组判断句；类型名另验，不再添加重复判断的固定说明；
- 五个风险高侧、七个保护低侧与七个保护高侧，共十九组句意素材；
- 六类组合段，以及无突出维度、数据不足、旧版本等回退文案。

素材不是十九句直接拼接。实现前应先把高频组合写成完整段落，并确认句间关系。此处只提出模块职责，没有在本轮创建运行代码或改变存储接口。

## 9. 接入前必须完成的核查

### 内容与规则

- 先按[新验收标准](result-copy-acceptance.md)检查长度、直白程度和四档连续性；类型名未定，不能标记为全部完成。
- 0.35／0.65 与近似并列 0.05 是否能在代表画像中选出合理内容；它们仍需试验，不作为测量结论。
- 同分不同机制、保护与风险并存、维度全中间、空 Path、双 Path、Shape 为 null 均有清楚表现。
- 文案只推断被选字段支持的内容，组合段必须同时满足所有条件。
- 相邻 Stage 不从“理性”跳成“盲信”；候选门槛附近也不生成相反人格。

### 验证分层

本轮已做：读取现有分界与方向；回放七组构造维度；比较其分数、Stage 与 Path；保存输入输出供复查。

本轮未做：正式 28 题答卷到文案的全链路接入、自动文案选择执行、真人试读、页面排版与分享图验证。七份正文为手工按候选规则撰写；算法回放证明的是数值一致性，不是文字有效性。

后续接入时，还需核对四舍五入：例如内部 69.99 若显示为 70，用户可能误以为应进入 Stage 4。显示精度与等级需有一致的展示规则，不在文案层偷改总分。

## 10. 建议采用的初步方案

保持用户确定的顺序：**分数判断先行、Stage 给出类型、两到三个维度主题形成个人描述。**

程度统一用第 1—4 档，明确标出递增方向，不另配强弱词。正文用两三句日常话写清具体特点。类型名重新拟定，旧版名称不再推荐。七份样例已压缩，仍需真人试读与用户审美确认。

交付以新验收标准为准。数字与字段核对通过，只代表内容有依据；一眼可懂和表达简短也必须单独通过。
