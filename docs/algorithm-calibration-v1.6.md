## 边界与结果

保留六层结构、85题题库及分值、28题与A12/B6/C6/D4配额、维度最低来源、语义组上限、100次重试上限、15～85显示标尺及30/50/70分档。不处理经历适用性，不按画像、题号或目标档位修分。

重点改善了“具体轻信与正常心动几乎同分”和“只在时间帮忙上失守却随换题大幅变分”。没有全面解决跨情境题目的可比性：部分承诺边界画像仍会跨约25分；新语义检查也仍有分段解释未通过的例子。连续性通过不代表分数含义或真人效度全部通过。

## 计分修改：替换判断证据合成

V1.5将整体判断弱与半强度短板等证据分别取最大值；当某项很弱时，其他能力会使均值较好，而短板又被0.5限幅。V1.6将它们合成同一个核心，减少并行分支：

```text
j = Low(J), jw = Low(J_weak), h = High(H), e = High(E)
core2 = 0.7*jw + 0.3*j
support2 = max(e,h)
supportedJudgment = core2 * [1 + 0.25*(1-core2)*support2]
P2 = max(supportedJudgment, 0.6*h)
```

70%最弱项与30%整体不是独立证据相加；它有意让短板主导，同时保留广度。E/H只支持一次，不形成循环。J_hole仍只解释，不参与计分。判断能力增强时，最弱项弱度与整体弱度均不增，因此P2与总分不增。

P1的独立严重度上限从30改为24，仍保留自身贡献及对P2/P3/P4的支持。P3/P4、线性High/Low和M抵减不变。第六层仍只有“最强路径+其余路径严重度之和的10%”，没有新增曲线或封顶分支。

理论证据上限随配置变为75+0.1*(24+62+70)=90.6，标尺末端同步为90.6→85。起点和30/50/70不变，未通过划档隐藏问题。

这些权重是工程候选，不是心理研究估计值。

## 抽题修改：统一内容覆盖表

仅增加“至少各抽一道”曾使一个画像更不稳定，未采用。将个人界限、过度帮忙和不对等投入混为同一执行类，也仍有明显漂移。因此最终用五条统一配置，按既有维度与semantic_group匹配，不改题库元数据：

| 内容方面 | 所属维度 | 占该维度本轮总容量 |
| --- | --- | --- |
| 资源／过度帮忙边界 | boundaries | 25%～40% |
| 不愿亲密／承诺压力 | boundaries | 25%～40% |
| 不对等投入的调整 | boundaries | 20%～40% |
| 信任建立 | calibration | 至少50% |
| 实际行为核查 | evidence | 至少60% |

每方面至少一道题；占比按题目最高有效分计算，不随答题选择改变。匹配同时要求维度与语义组，避免把只计manipulation的请求题误作边界证据。

分类集中在`QuestionSampler.CONTENT_COVERAGE`。同一统计与约束用于新抽题、候选优先级、最终校验、题池缺失检查及进度恢复。优先级补内容缺口；上下限在最终验证，不满足时有限重试，不放宽规则。

三方面只控制内容混合，不能证明题目难度等值；这些分类也是工程内容蓝图，不是经真人验证的心理因子。未扩展归一化接口，也没有在不同调用路径使用两套评分。
