# V1.4重复作答稳定性：第二轮调查

2026-10-15。已确认用户批准的V1.4正式代码、三个对应测试和算法文档均已落盘。本轮为只读调查；运行时代码、题库和抽题约束未变。

## 结论与优先级

优先调查边界题的内容覆盖及其经P3传递的放大，再处理止损/P4。暂缓经历适用性结构修改，保留M、情感敏感性和各层原调控。继续压缩最终分数不是本轮推荐方向。

当前抽题满足每维至少2题，却允许同一维度的具体证据方面大幅变化：拒绝具体请求、不对等投入调整、心理边界/提前规划并不能自动视为可互换的同强度测量。容量归一化只统一分值范围，不能校准题组内容构成和经验难度。

本轮证据支持这一优先级，不证明已找到能稳定改善所有人群的修改。

## 方法与样本

冻结此前512名模拟者对整个正式题库的答案，每人20个题组，共10,240次完整评分；只换题组，不加入状态或答题噪声。另用8个先前冻结画像、每人300组题交叉检查。所有问卷继续满足28题、A12/B6/C6/D4、每维至少2来源、语义组至多2题、重试至多100次。

生成模型使用原计分键、情境偏差和有限经历，跨维题选择可能表现为多个特征间的折中，属于模拟假设。旧画像交叉检查能减少对单一生成模型的依赖，但仍不是独立真人证据。所有模型均未据本轮输出改答案。

另在验证和最终复核各128名模拟者、各8个题组中，对每个可替换位置随机选择一个保持全部约束的同类型替代题，完成44,948次合法单题替换。保持同一人对每题的冻结答案，用于排除总题数、类型配额和不合法覆盖造成的混杂。替换题的内容可能不同，因此不等于相邻选项变化。

## 1. 波动首先集中在边界和止损证据

诊断：把某一底层维度在20组题中的值，暂时固定为该人的20组均值，其余输入照常变化，再沿原第四、五、六层计算。这个人均值在真实单次答题中不可获得，仅用于定位。

|诊断固定项|样本内总同人方差下降|同人分差95分位|
|---|---:|---:|
|均不固定|—|18.21|
|边界|36.1%|13.97|
|止损|19.9%|15.73|
|边界与止损一起|56.7%|11.24|
|情感分化|13.8%|16.75|
|四项情感维度一起|8.6%|18.09|
|自我校准M|0.3%|18.19|

这些是不可部署的诊断性固定，不是各维度的可相加因果贡献。交互与相关性存在，不能把百分比相加或据此重设维度权重。固定全部维度后分差为0，符合确定性计分；第三层乘100、第四层除100的适配与直接单位输入逐例一致到1e-9。

M固定仅减少约0.3%的样本内同人方差，不支持为解决重复测试波动而修改原M保护。冻结P3或P4输入也明显降低波动，但不能据此削弱它们本来要识别的风险。

旧画像交叉检查：

|画像|原同人标准差|固定边界后的标准差|固定止损后的标准差|
|---|---:|---:|---:|
|很容易被理解和细节打动，但会核实、拒绝和退出|6.76|6.76|6.76|
|偶尔美化或拖延，但能调整投入、接受提醒|1.61|1.61|1.61|
|能识别问题，但怕让人失望，经常继续不对等投入|3.76|1.47|3.76|
|能看清问题、拒绝具体要求，但舍不得结束关系|2.28|2.28|1.99|
|不太容易心动，但常怕让人失望而过度帮忙|15.05|0.37|15.05|

边界并非所有画像的主因：易心动但稳健者固定边界后仍波动，固定四项情感维度后标准差6.76→0.25；中等画像相应1.61→0.19。后续必须同时保留情感画像检查，不能只针对边界画像优化。

## 2. 具体反例与式子定位

一名模拟者的稳定答卷在两组题中，止损同为0.833，但边界由0.600变为0.222，P3由0.343变为0.965，总分19.86→63.79。这是同人情境反应在不同题组中被不同比例抽到的结果。

更严格的单题替换：同一名较高经历模拟者，A34（未来会变好所以继续不对等付出）替为A31（不愿亲密接触却怕对方失望而配合），其余27题不变，全部原约束仍成立。只有边界维度改变：0.333→0.500；总分58.05→29.22，差28.83分。这说明不同方面的边界反应可以被当前抽题当作替代证据。不是同一道题答案变了，也不是算式不连续。

链路为：

```text
不同题组的边界证据构成
→ B = sum(score) / sum(capacity)
→ Low(B) = clip((0.8 - B) / 0.6, 0, 1)
→ core3 = min(High(J), Low(B))
→ P3 = core3 * (1 + 0.2 * (1 - core3) * High(E))
→ 第六层严重度曲线、max主体、共现调控、M和分数标尺
```

当判断较好、边界成为P3主要限制项时，边界变化直接进入Low(B)，其线性段斜率绝对值1/0.6；P3与严重度再传递变化。原短板机制有意义，不能为减少方差而直接删去。优先处理进入该链路的证据构成。

合法单题替换统计：

|样本|合法替换次数|绝对分差95分位|最大分差|
|---|---:|---:|---:|
|validation|22486|3.97|35.31|
|holdout|22462|3.30|36.74|

绝大多数替换影响较小，大分差集中于尾部。B03被替换时分差95分位19.61，高于本次其他常见题，需优先审查其与其余证据的搭配；不能据此认定B03本身应删。

## 3. 当前抽题存在明显的来源偏向

10,240个不同种子的题组中：

- 每次出现：A05, A08, A25, B03, C03, C13, C17。
- 一次未出现：A26, C14。

“每次”和“未出现”限定本轮种子，非对全部可能种子的形式证明。需与题库、配额和优先级规则共同解读。

抽题优先级先比较同时补足几个缺失维度，再偏向关键维度非A来源，之后才比较语义组。由此多维题容易获得高优先级；语义新颖优先又使已有B03同组的C14处于劣势。这是取题优先级和硬约束交互的表现，不能由来源频率直接判定测量质量。

## 4. 约束可行性与下一轮候选

先只做可行性，不把可抽出来等同于提高稳定性。每种约束使用1000个新种子、原100次重试上限：

|额外约束|生成失败|平均重试（成功者）|最高重试|
|---|---:|---:|---:|
|边界至少1道C情境题|0/1000|15.14|97|
|止损至少1道C情境题|0/1000|6.92|61|
|两者均至少1道C情境题|321/1000|40.90|100|

两类均强制C来源时32.1%失败，是当前生成过程在该约束下失败，不是证明题池在数学上不可行。不能直接添加此约束后靠延长重试或放宽保护掩盖。

按现有题意暂分边界内容方面，未改正式元数据：

- 具体拒绝/界限执行：A31、B10、B18、C06、C09、C10。
- 不对等投入/关系维护：A34、A37、B03、B09、C14。
- 心理边界/提前规划：A04、D08。

分类属于待审查的内容蓝图，不是经过心理测量校准的因子。A04和D08的证据意义仍各有区别，不据此自动减权或删除。

|候选内容覆盖约束|生成失败|平均重试|最高重试|
|---|---:|---:|---:|
|至少1道具体拒绝/执行类|0/1000|3.30|20|
|至少2道具体拒绝/执行类|0/1000|9.53|57|
|至少1道具体拒绝类，加1道A39/C05/C16停止选择来源|0/1000|4.47|38|

下一轮优先离线比较这三种覆盖约束，不改最终标尺、M和P1—P4表达式；先检验单独约束再组合。先增加内容覆盖约束的原型，以当前题库检验同人分差和画像区分；若后置拒绝导致重试失败，再调查原优先级表达式如何纳入来源缺口，不重构整套抽题器。

验收须同时比较：稳定答卷换题分差95分位及均值、阶段切换、合法单题替换尾部、原8画像（尤其情感画像）、新增低于20/30分、生成失败率与重试次数。使用固定答卷和预先冻结候选，另留未参与方案选择的模拟者；不能只挑改善的画像，也不能据本轮诊断中的“固定人格均值”实际计分。

## 验证和边界

运行时算法仍为V1.4；本轮没有写入新的评分、抽题、题库或UI修改。原V1.4的14项测试与30,720次回放记录有效，本轮未无理由重复运行无关检查。调查结束时重新核对8个运行时文件与题库的SHA-256，保持完全一致。

本报告的定住维度、合法替换和抽题频率分析是可复现的模拟诊断，不是实际预测准确率。没有直接估计题目难度或信息量，不能把内容覆盖称为心理测量等值。
