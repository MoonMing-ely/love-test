  • 首页、结果页、关于页的右上圆圈同步回调 0.5%，共享描边系数为 0.9。没有修改题库 Markdown、运行 JSON、题目措辞或评分算法，两份题库文件 SHA-256 与本轮修改前一致。
  • 描边设计值统一乘以 0.9。Firefox 的原生 border / outline 会映射到物理像素，实际细线可能呈阶梯变化；SVG 与灰色分隔线直接使用小数尺寸。已将边框取整差值补回内边距，保持题干与文字可用宽度。
  • Node 测试 13/14 通过，唯一失败是已有的题库维护源与运行 JSON 不一致；本轮未同步题库。Firefox 不支持 pretty，其他浏览器及实体手机未做本轮视觉实测。

实现与原始记录

CSS 使用统一的高度、间距、描边和圆圈变量；额外空间由 Grid 的弹性轨道吸收。布局脚本读取整组选项的自然高度与边框基准，保留原 DOM ID、答题存储及跳转接口，没有写入题目专属坐标或固定按钮高度。阴影的不可见外延被限制在 17px 留白内，避免额外滚动条。
