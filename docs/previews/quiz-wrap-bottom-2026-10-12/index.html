验证范围与差异

  • 检查题框与选项边缘一致、题干左对齐、严格标点、完整文本、按钮最低高度与间距、重复及实际 resize 后稳定性、整页滚动与进度可达性；横屏灰线保持原细线粗细。
  • 固定 C10、A21、C02、C24 与最短题 A28 测量，C24 同时覆盖最长题干和长选项。最长内容自然增高，无纵向裁剪。
  • 真实完成 28 题；选答、上一题、返回未答题、刷新恢复、关于页返回和结果页跳转通过。100% / 200% 浏览器缩放在同一 CSS 视口的几何与换行完全一致。
  • 实际 HTTP 字体加载、题干字号变化、200% 字号和状态提示通过；禁用 Intl.Segmenter 后全部 96 道题的条件回退通过。
  • 首页、结果页、关于页在手机、临界横屏与宽横屏的前后几何对比一致。题目 Markdown、运行 JSON 的 SHA-256 与本轮修改前相同。
  • Node 测试 13/14 通过。唯一失败是既有题库维护源与运行 JSON 不一致，修改前快照同样失败；本轮未生成或同步题库。
  • 本机 Firefox 不支持 pretty，实际验证的是 wrap 与条件 balance。支持 pretty 的浏览器尚需视觉复核；本次也未在实体手机上验证浏览器工具栏伸缩。

白框现在随视口填高，较高视口的 A 会明显变大，这是本轮确认的布局规则；长内容仍能滚动。不同浏览器的原生断行结果可能存在差异。
