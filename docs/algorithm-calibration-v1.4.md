# 算法V1.4：保守放缓严重度激活曲线

2026-10-15，经用户确认写入。基于V1.3，只调整第六层原平滑曲线的过渡宽度；各层职责、接口与题库保持原定义。

## 表达式与保留机制

```text
旧：t = clip((P - threshold + 0.20) / 0.45, 0, 1)
新：t = clip((P - threshold + 0.30) / 0.65, 0, 1)
activation = t² * (3 - 2t)
severity = activation * (anchor + 25 * (P - 0.6))
```

配置为 `ACTIVATION_BEFORE=0.30`、`ACTIVATION_AFTER=0.35`。曲线中心仍是threshold+0.025；最大激活斜率由3.333降至2.308，降低约30.8%，不意味着最终分差也降低30.8%。

P1—P4构建、各路径阈值/锚点、max/均值主体、多路径增益、M抵减及V1.3的15～85标尺全部保留。低风险完整答卷最低15、最高85；数据不足仍为null。M只抵减既有风险，不变成风险加分项。保留情感敏感性的原贡献。

AlgorithmConfig与第六层版本为1.4；第三层1.1、第四层1.2、第五层1.1，结果信封仍为3。旧1.3结果通过现有版本守卫提示重测，不自动重算旧分；有效未完成答题仍按原抽题版本和题库修订号恢复，完成时采用当前算法。

## 写入后的低分专项复核

正式代码回放512名模拟者、三种条件、各20次，共30,720次评分，与已批准候选逐项一致。

| 指标（重复评分次数，非独立人数） | V1.3 | V1.4 |
|---|---:|---:|
| 最低分 | 15 | 15 |
| 正好15分 | 487 | 487 |
| 低于20分 | 6,576 | 6,440 |
| 低于25分 | 10,103 | 10,215 |
| 低于30分 | 11,091 | 12,536 |

原本低于20分的6,576次评分中，无一次继续下降，平均上升0.112，136次升至20分以上；没有原本≥20分的新跌至20分以下。原本≥50分的新跌至30分以下为0次。

结论：此前V1.3已经把完整答卷的0分映射为15，此保护继续有效。本次极低分只有小幅改善；正好15分次数不变，20～30分数量反而增加，不能说低分段整体上移或低分问题全面解决。这是放缓中段曲线的已知代价，不通过额外提分补丁掩盖。
