# 结果截图分享

结果页沿用原有「分享结果」按钮。`result.js` 负责展示结果；`result-share.js` 独立负责截图、图片预览、保存和可用时的系统图片分享。

截图使用本地固定版本 html2canvas 1.4.1，源码与许可位于 `js/vendor/`，运行时不请求 CDN、不上传结果。

生成图片时只在 html2canvas 的克隆文档中展开结果滚动区、增加外框与页面高度，保留当前屏幕宽度和原有样式。原页面的布局与滚动位置保持不变。截图包含标题、最终分数、所有分层数据及页面操作区域。

PNG 在内存中生成，以 Blob URL 提供预览与下载。关闭预览或离开页面时释放 URL。不保存额外答题记录。

支持 `navigator.canShare({ files })` 的浏览器显示「分享图片」。生成截图和打开系统分享使用两次独立点击，避免异步截图消耗浏览器要求的用户操作授权。取消分享保留预览；分享失败仍可保存图片。手机浏览器可长按预览图片保存。

空结果禁用分享；生成中阻止重复点击；生成失败显示可重试提示。Canvas 面积与最长边限制用于降低长图的内存需求，因此特别长的结果可能降低导出像素倍率。

html2canvas 是按页面元素绘制图片，并非操作系统截图。浏览器字体、部分 CSS 效果可能存在细微差异。系统分享入口取决于浏览器与操作系统支持。
