# 结果截图分享

结果页沿用原有「分享结果」按钮。`result.js` 负责展示结果；`result-scroll.js` 同步独立翻页条与内容滚动；`result-share.js` 独立负责截图、图片预览和保存。

截图使用本地固定版本 html2canvas 1.4.1，源码与许可位于 `js/vendor/`，运行时不请求 CDN、不上传结果。

截图目标为白色的 `.result-content` 节点，排除父页面的蓝色页眉、页脚、导航、底部按钮和状态提示。仅在克隆文档中展开内容滚动区、清除焦点外框，并保留当前文字宽度；导出宽度在原内容区外左右各增加24px白边，上方留40px、下方留24px。高度按完整内容计算，不通过压缩文字宽度来增加白边。生成图片使用白色背景，原页面的布局与滚动位置保持不变。截图包含标题、最终分数、程度标签、完整解读、能力概览与结语；算法明细已从页面移除。

PNG 在内存中生成，以 Blob URL 提供预览与下载。关闭预览或离开页面时释放 URL。不保存额外答题记录。

预览只显示两个操作：左侧黑字「关闭」，右侧粉字「保存」。弹窗外框为粉色，预览图框为蓝色圆角，粗细为外框的 70%。保存后由用户手动分享；手机浏览器也可长按预览图片保存。

空结果禁用分享；生成中阻止重复点击；生成失败显示可重试提示。Canvas 面积与最长边限制用于降低长图的内存需求，因此特别长的结果可能降低导出像素倍率。

html2canvas 是按页面元素绘制图片，并非操作系统截图。浏览器字体、部分 CSS 效果可能存在细微差异。

## 配色兼容检查

html2canvas 1.4.1 的颜色解析器不支持 `color-mix()` 和 `color()`。结果程度标签采用与原混色近似等效的 `#5480c8`，避免浏览器能显示、生成图片却失败。回归测试读取实际 CSS，并调用固定截图库的真实颜色解析器；截图调用、预览和释放仍由已有流程测试覆盖。这不替代真实浏览器 PNG 验收。
