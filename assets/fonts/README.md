# MiSans

本项目题干使用小米 MiSans Regular（400 字重）。其他文字沿用全站字体栈。

- 官方介绍：https://hyperos.mi.com/font/zh/
- 授权协议：随附的 [MiSans-LICENSE.pdf](MiSans-LICENSE.pdf)
- 来源：本机 `ttf-misans 4.003-2` 提供的 `MiSans-Regular.ttf`。
- `MiSans-Regular.woff2` 使用 `woff2_compress` 压缩完整原始字体；未裁剪字符或修改字形，保留字体内版权信息。

字体与项目一同提供，无需访问第三方字体服务，也不要求访问者安装 MiSans。
