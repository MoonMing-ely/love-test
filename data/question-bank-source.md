# 情感被骗指数测试：第三版候选题库（12维评分版）

> 保留当前人工初筛版本的题目与选项，仅将评分体系重构为 **12 个底层维度**。现存 **96 题**。

## 12 个底层维度

| 标记 | 维度 | 含义 |
|---|---|---|
| **认** | 人格认可敏感 | 被看见、被理解、被认可时的情绪触发强度 |
| **需** | 被需要敏感 | 因对方依赖、求助、脆弱而增加投入的倾向 |
| **特** | 特殊性放大 | 把少量共鸣或特殊互动快速解释为关系独特 |
| **稀** | 稀缺性判断 | 把“很少遇到”进一步理解为“不可替代”的倾向 |
| **校** | 关系校准 | 判断关系实际阶段、双方投入和关系定义是否匹配 |
| **证** | 行为证据意识 | 言语与长期行为冲突时对现实行为的重视程度 |
| **操** | 操纵识别 | 识别情绪推动、隐性索取、关系话术和责任转移的能力 |
| **合** | 现实回避/合理化 | 出现异常后替对方解释、延迟确认或回避结论的倾向 |
| **边** | 投入边界 | 时间、精力、金钱、帮助等投入是否能保持边界 |
| **止** | 止损能力 | 关系失衡、舍不得或已有投入时停止继续加码的能力 |
| **分** | 心理分化能力 | 能否区分喜欢/信任、理解/接受、帮助/关系升级、舍不得/值得继续 |
| **自** | 自我校准能力 | 是否意识到自己的判断可能受恋爱情境和经验不足影响 |

## 与结果页四维的关系

- **情感易感性**：主要由 `认 / 需 / 特 / 稀` 合并。
- **关系判断力**：主要由 `校 / 证 / 操` 合并。
- **投入边界**：主要由 `边`，并参考 `分`。
- **止损能力**：主要由 `合 / 止`，并参考 `分`。
- **心理分化能力（分）** 与 **自我校准能力（自）** 作为跨维度保护/修正项，不建议简单并入单一大维度。

> 评分说明：每个选项后的 `+0 ~ +3` 是该底层维度的建议原始分。不同维度的“高分”含义并不一致：例如 `认/需/特/稀/合` 高通常代表风险入口更强，而 `校/证/操/边/止/分/自` 高通常代表保护能力更强。最终不要把 12 维直接求和。

### 2. 再合并成 4 个展示维度

- 情感易感性 ← 人格认可敏感、被需要敏感、特殊性放大、稀缺性判断
- 关系判断力 ← 关系校准、行为证据意识、操纵识别
- 投入边界 ← 投入边界 + 心理分化修正
- 止损能力 ← 现实回避/合理化、止损能力 + 心理分化修正

### 3. 两个跨维度修正项

- **心理分化能力**：用于降低“友善/共情/愿意投入”被误判为高风险的概率。
- **自我校准能力**：用于处理“没经历过但自认一定理性”的偏差，并可调整自陈题权重。

### 4. 最终被骗风险应使用组合逻辑

例如：

> 高人格认可敏感 + 高特殊性放大 + 高稀缺性判断
> 只有在关系校准、行为证据、投入边界或止损能力偏弱时，才应显著提高总风险。

这样可以避免把“很容易与人建立联系的人”直接判成“很容易被骗的人”。
